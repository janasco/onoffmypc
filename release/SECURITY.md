# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the security contact published at <https://onoffmypc.com/.well-known/security.txt>.

Do not open a public issue containing credentials, private user or device data, detailed exploit instructions, or an unpatched vulnerability.

Include the affected release or artifact name, version, platform, and a concise description. Do not test against accounts, devices, or infrastructure you do not own or have explicit permission to assess.

Release checksums help detect accidental corruption but are not a substitute for a private vulnerability report.
