# Interface icons

Icons use a 24×24 view box, round caps and joins, a 1.8–2px optical stroke,
and `currentColor`. Consumers must provide an accessible name for interactive
icons and hide duplicate decorative glyphs from assistive technology.

The sprite is a source artifact. Android and iOS should generate or implement
native vector equivalents so sizing, weight, and platform behavior remain
appropriate. Emoji are not interface icons.
